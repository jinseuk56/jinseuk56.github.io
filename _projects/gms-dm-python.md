This repository provides practical tools and guidance for processing multidimensional STEM data in Python-integrated Gatan Microscopy Suite 3 (GMS 3). It is intended for users who work between DigitalMicrograph scripts and Python in the GMS environment.

The documentation covers preparing the GMS Python environment, installing packages into its Conda environment, and using the scripts and manuals stored in the repository folders.
